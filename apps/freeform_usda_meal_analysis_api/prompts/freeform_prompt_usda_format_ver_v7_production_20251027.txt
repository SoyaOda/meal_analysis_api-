EDGE-BASED DETECTION METHOD (2025 Research-Based)

Apply systematic multi-pass scanning to detect ALL items, especially small components:

1. PRIMARY SCAN - Main items
   - Large proteins, starches, vegetables
   - Use edge detection to identify item boundaries
   - Estimate volume from area and height

2. SECONDARY SCAN - Often overlooked items
   - Scan plate edges and corners for sauces/condiments
   - Look for glossy/wet surfaces indicating oil/butter (10-20g adds 90-180 kcal)
   - Check for white/cream colored areas (mayo, aioli, sour cream)
   - Identify garnishes using color contrast (green herbs, red tomatoes)

3. VISUAL CUES FOR HIGH-CALORIE ITEMS
   - Shiny surface = oil/butter coating
   - Creamy white = dairy-based sauce
   - Dark pools = reduction/gravy
   - Scattered specs = nuts/seeds

SPATIAL WEIGHT ESTIMATION METHOD (2025 Best Practice)

Use visual references and spatial reasoning for accurate weight estimation:

1. ESTABLISH SCALE
   - Plate diameter: typically 25-27cm
   - Use any visible references (utensils, hands, phone)
   - Create mental coordinate grid over the plate

2. ESTIMATE VOLUME
   - Measure food area relative to plate
   - Estimate height from shadows and texture
   - Apply shape factor (flat=0.5, mounded=0.7, solid=1.0)

3. CALCULATE WEIGHT
   - Volume (cm³) × Density (g/cm³) = Weight (g)

   Density Guidelines (FAO/INFOODS validated):
   - Meat/fish (cooked): 1.1 g/cm³
   - Rice/pasta (cooked): 0.85 g/cm³
   - Bread/baked goods: 0.3-0.5 g/cm³
   - Raw vegetables: 0.4 g/cm³
   - Cooked vegetables: 0.9 g/cm³
   - Cheese: 1.1 g/cm³
   - Sauces/dressings: 1.0 g/cm³
   - Oil/butter: 0.92 g/cm³
