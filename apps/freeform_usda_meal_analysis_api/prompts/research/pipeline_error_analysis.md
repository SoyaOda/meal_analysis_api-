## 3. 誤差パターン分類

### 3.1 カテゴリA: VLM食材認識失敗（不可視成分）

**影響**: ラベルカロリーの27-38%を占める成分が検出されない

| 画像 | 見逃された成分 | カロリー | 全体比率 |
|-----|--------------|---------|---------|
| test_food22 | オリーブオイル | 177 kcal | 27% |
| test_food26 | イタリアンソーセージ | 301 kcal | 38% |
| test_food27 | マヨネーズサラダ | 250 kcal | 23% |

**原因**:
- オイルは視覚的に検出困難
- ソーセージがパスタに埋もれている
- マヨネーズは白色で視認性が低い

**改善提案**:
- プロンプトで「調理に使用された油を推定せよ」と明示
- パスタ料理には「肉類の存在を確認」を強調

---

### 3.2 カテゴリB: VLM重量推定の体系的バイアス

**Geminiの傾向: 過大評価（+30%以上）**
```
test_food38: 681 → 1178 (+73%) - ビーフシチュー
test_food11: 499 → 672 (+35%) - ラザニア
test_food44: 518 → 686 (+32%) - ベイクドパスタ
test_food48: 546 → 800 (+47%) - ビーフシチュー+ライス
test_food24: 370 → 543 (+47%) - チキンサラダ
```

**GPTの傾向: 過小評価（-30%以上）**
```
test_food22: 646 → 400 (-38%) - シュリンプパスタ
test_food26: 786 → 400 (-49%) - ソーセージパスタ
test_food27: 1069 → 600 (-44%) - 複合定食
test_food40: 974 → 640 (-34%) - ピザ
test_food28: 944 → 550 (-42%) - ピザ
```

**分析**:
- Geminiは**ボリューム感のある料理を大きく見積もる**傾向
- GPTは**高カロリー成分を見逃すか、重量を控えめに見積もる**傾向

---

### 3.3 カテゴリC: モデル間の極端な乖離

**test_food38が最も顕著な例**:
```
正解: 681 kcal
GPT:  ~400 kcal (-45%)
Gemini: 1178 kcal (+73%)
乖離幅: 118%ポイント
```

**ラベル内容**:
- ビーフシチュー 380g: 456 kcal
- サワークリーム 20g: 40 kcal
- サラダ（アボカド60g含む）: 185 kcal

**推定原因**:
- Geminiはシチューの重量を過大に見積もり（おそらく600g以上と推定）
- GPTはアボカドやサワークリームなど高脂肪成分を見逃し

---

### 3.4 カテゴリD: ピザ特有の問題

**高誤差率**: test_food28, 40, 49がすべてピザ

| 画像 | ラベル | API | 誤差 | ピザタイプ |
|-----|-------|-----|-----|----------|
| test_food28 | 944 | ~550 | -42% | チーズ+オリーブ |
| test_food40 | 974 | ~640 | -34% | プロシュート+オリーブ |
| test_food49 | 602 | 416-818 | ±30% | チーズピザ |

**分析**:
- ピザのサイズ（直径）推定が困難
- トッピングの量推定が不正確
- GPTは特にピザを過小評価する傾向

---

### 3.5 カテゴリE: 複合定食の累積誤差

**test_food27（最高カロリー: 1069kcal）の内訳**:
```
白米 200g: 260 kcal
牛肉炒め 150g: 270 kcal
豚肉炒め 170g: 289 kcal
マヨネーズサラダ 100g: 250 kcal
```

**問題点**:
- 4品すべてを正確に認識・計量する必要
- 各品の重量誤差が累積
- マヨネーズサラダは視覚的に低カロリーに見える

## 4. Pipelineコンポーネント別分析

### 4.1 VLM（Vision Language Model）

| 問題 | 影響度 | 発生頻度 |
|-----|-------|---------|
| 不可視成分（オイル、マヨ）の見逃し | 高 | 中 |
| 重量推定バイアス（モデル依存） | 高 | 高 |
| 複合料理の成分分離失敗 | 中 | 中 |
| ピザサイズ推定困難 | 中 | 低 |

**改善優先度**: ★★★★★（最重要）

### 4.2 USDA Database (Retriever/Reranker)

**調査済み事項**:
- 総エントリ数: 13,564件
- Composite料理: USDAには単一エントリなし（例: パスタ+ペスト）
- 状態バリエーション: 乾燥/調理済みの混在（例: グレービー113エントリ）

| 問題 | 影響度 | 発生頻度 |
|-----|-------|---------|
| 適切なエントリの選択 | 中 | 低 |
| 状態（dry/prepared）の誤選択 | 中 | 低 |
| 調理法バリエーション | 低 | 低 |

**結論**: DB/Retriever/Rerankerは現状で適切に機能している。主要な誤差源はVLM。

### 4.3 Prompt Design

| プロンプト | 特徴 | 30%+誤差率 | 評価 |
|-----------|------|-----------|------|
| Original | シンプル、基本ルール | 8.0% | **最良** |
| D (Improved) | 詳細ルール追加 | 8.8-9.6% | 悪化 |
| E (Refined) | 状態指定強化 | 10.1-12.8% | 悪化 |
| F (Hybrid) | D+E混合 | 10.8-13.6% | 最悪 |

**重要な発見**:
- プロンプトの複雑化は改善に繋がらない
- 追加ルールがVLMの判断を混乱させている可能性
- Originalプロンプトのシンプルさが最適

## 5. モデル特性比較

### 5.1 GPT-5.1

**長所**:
- 過大評価が少ない
- 一部の複雑料理で良好な結果

**短所**:
- 結果のばらつきが大きい（CV 5-13%）
- 高脂肪成分を見逃しやすい
- ピザを過小評価する傾向

### 5.2 Gemini-3-Flash

**長所**:
- 一貫性が高い（CV 2-8%）
- 同じ画像に対して安定した結果

**短所**:
- ボリューム感のある料理を過大評価
- 特定画像で極端な誤差（test_food38: +73%）
- 新プロンプトとの相性が悪い

---

## 6. 結論と推奨事項

### 6.1 主要な発見

1. **誤差の主因はVLMの重量推定バイアス**（Pipelineの最上流）
2. **不可視成分（オイル、ソース、マヨネーズ）が大きな誤差源**
3. **プロンプトの複雑化は逆効果**（D, E, F, G全て悪化）
4. **モデル選択が重要**: Geminiは一貫性重視、GPTはばらつき許容
5. **プロンプト改善の限界に到達**: これ以上の改善は別アプローチが必要

### 6.2 推奨事項

#### 即時対策
1. **Originalプロンプト + Gemini-3-Flash を使用**
   - MAE: 14.5%, 30%+誤差率: 8.0%, CV: 1.9%
2. **追加プロンプト（D, E, F, G）は採用しない**

#### 中長期対策（プロンプト外）
1. **Multi-VLMアンサンブル**: GPT+Geminiの結果平均化
   - 極端誤差（test_food38等）の削減が期待
2. **ユーザー補正機能**: 重量入力オプション
   - 重量誤差の根本解決
3. **VLMモデルアップグレード**: 次世代モデル待ち
   - 根本的な精度向上

### 6.3 プロンプト改善の限界

```
┌─────────────────────────────────────────────────────────────┐
│  テスト結果から得られた結論:                                │
│                                                             │
│  ・追加ルール（詳細化）   → 改善せず悪化                   │
│  ・一般化ルール（抽象化） → 改善せず悪化                   │
│  ・ハイブリッド（混合）   → 改善せず悪化                   │
│                                                             │
│  → Originalプロンプトが最適解                              │
│  → プロンプトエンジニアリングでの改善は限界                │
└─────────────────────────────────────────────────────────────┘
```

### 6.4 期待精度

| 構成 | MAE | 30%+誤差率 | CV |
|-----|-----|-----------|-----|
| **推奨: Original + Gemini** | **14.5%** | **8.0%** | **1.9%** |
| Original + GPT | 14.8% | 8.0% | 5.1% |
