## What was learned
- プロンプトの複雑化（D/E/F/G）は一貫して改善しなかった。
- 主要誤差はVLMの食材認識・重量推定に起因し、retriever側の寄与は相対的に小さい。
- 不可視成分（油脂、ソース）見逃しと、料理体積の過大/過小推定が高誤差の中心。

## PDCA rule derived
- Prompt変更は「最小変更 + 1仮説」に限定する。
- MAEだけでなく30%超誤差率を必須ゲートにする。
- モデル切替を優先的に試す（thinking対応モデルを中心に比較）。

## Next hypothesis examples

- モデルアンサンブル（上位2モデル平均）で極端値を抑える。
