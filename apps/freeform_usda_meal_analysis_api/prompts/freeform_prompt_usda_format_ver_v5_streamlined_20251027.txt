SPATIAL WEIGHT ESTIMATION METHOD (2025 Best Practice)

Use visual references and spatial reasoning for accurate weight estimation:

1. ESTABLISH SCALE
   - Plate diameter: typically 25-27cm
   - Use any visible references (utensils, hands, phone)
   - Create mental coordinate grid over the plate

2. ESTIMATE VOLUME
   - Measure food area relative to plate
   - Estimate height from shadows and texture
   - Apply shape factor (flat=0.5, mounded=0.7, solid=1.0)

3. CALCULATE WEIGHT
   - Volume (cm³) × Density (g/cm³) = Weight (g)

   Density Guidelines (2025 validated):
   - Meat/fish (cooked): 1.1 g/cm³
   - Rice/pasta (cooked): 0.85 g/cm³
   - Bread/baked goods: 0.3-0.5 g/cm³
   - Raw vegetables: 0.4 g/cm³
   - Cooked vegetables: 0.9 g/cm³
   - Cheese: 1.1 g/cm³
   - Sauces/dressings: 1.0 g/cm³

PORTION SIZE VALIDATION

Typical single servings (use as reality check):
- Protein: 120-200g (palm-sized)
- Starch: 150-250g (fist-sized)
- Vegetables: 80-150g (handful)
- Total meal: 400-800g

If your estimate exceeds these ranges, reconsider your volume calculation.

USDA NAMING RULES

- No cooking methods in search_name

description: Modifiers only

- "raw, fresh", "cooked, frozen"
- "restaurant style", "homemade"

KEY PRINCIPLES

1. ALWAYS use spatial reasoning - never guess weights
2. Every weight needs an estimation_basis explaining the visual evidence
3. Be conservative - when uncertain, use lower estimates
4. Validate total weight (400-800g typical)
5. Distinguish similar foods carefully:
   - Chicken vs pork: color and grain pattern
   - Fish vs chicken: flakiness and texture
   - Potato wedges vs chips: thickness and shape

6. Include ALL visible foods - don't merge items:
   - List salad components separately if distinguishable
   - Separate sauces and condiments
   - Count each vegetable type

CONFIDENCE SCORING:
- 0.9-1.0: Clear view, standard portion
- 0.7-0.8: Partially visible, typical food
- 0.5-0.6: Obscured or unusual item
- <0.5: Highly uncertain

❌ Overestimating portions (e.g., 400g of chicken - unrealistic)
❌ Missing small items (sauces, garnishes, nuts)
❌ Confusing similar proteins (chicken/pork/fish)
❌ Using search names with cooking methods
❌ Ignoring visual scale references
