### 🔴 探索結果＝天井マッピング（再試行しない negative）
**prompt / schema / retrieval / モデル選択は全て天井**。realistic range(200-1500kcal)は ~20-24% の純粋 variance floor、系統 bias は set-specific（小皿 over × 大皿 under が相殺し本命レンジは bias≈0）。
- **モデル**: pro 撤回（独立実測 GT で calorie/recognition とも flash への頑健優位なし・3セットで符号 flip。frozen-50 の pro 優位は GPT-5-pro 推定 GT のアーティファクト）。cross-provider(embedding/reranker/VLM-native)全スロットでクリーン勝ち無し。`docs/MOZU_MODEL_DECISION_20260603.md` / lesson `20260605_cross_provider_retrieval_no_clean_win`。
- **E3 不確実性診断**: 利用可能な不確実性信号（無課金 proxy 9種 + SC 分散）は誰もカロリー誤差を予測しない（pooled N=253, CV ρ+0.048 CI[−0.08,+0.17], AUC 0.51）。高誤差画像の 46/52/46% が低CV=「自信を持って間違える」（系統 bias 支配でサンプル不変）。→ **E9(不確実時1問)/E18(tiered routing) の安価信号版は不成立**。lesson `20260605_e3_uncertainty_no_error_signal_but_sc_median_robust_at_pooled_N`。
- **E1 v15/v18 schema 分離**: workflow で過去9失敗 lesson 精読→HOLD+pre-mortem→pooled 3セット。**pooled −6.21pt だが set-specific(符号 flip +0.46/−1.69/−14.26)** ＝ global な calorie deflation で N5k 小皿のみ修正・eye-level wash・大皿悪化(slope↓=逆方向)・recognition 非汎化＝**REJECT**（過去 v14/16/17 も不成立）。lesson `20260606_e1_v18_identity_separation_set_specific_deflation_not_generalizing`。
- **E7 tail**: selective-E7（単一/支配アイテム→top1）は無効（mean 悪化・p90 不変＝tail は E7 機構の表裏）。`20260605_e7_*` の tail follow-up。
- **n=50 の限界**: 小効果 data-independent lever は n=50 単独では判定不能（VLM draw 分散 ±3pt 支配 + subgroup データ不足）→ **pooled rotation 必須**。lesson `20260605_e12_self_consistency_v2_parallel_no_reproduce_at_n50`。

## Non-Negotiables（継続）
- 採用判定は原則 pooled rotation（小lever は n=50 単独で判定しない＝draw-noise ±3pt）+ Ground truth 総カロリー比較 + 安定性（複数 run）。
- 過学習防止: prompt に評価データ固有情報を埋め込まない。calibration は eval と disjoint・blind holdout で検証。
- PDCA 評価は原則 `use_vlm_cache=false`（同一 VLM の retrieval-only A/B 等の isolation 目的では cache=true を justified exception として明記）。
- 本番（Cloud Run/Firestore）操作・deploy・commit/push は要ユーザー明示指示。
- promote 主張は run 自身の artifact のみ引用（cross-run 値は文脈）。
- portion = 決定的メトリクス（`dish_match_metrics.portion_score_0_5`）、LLM portion は advisory。global calibration は VOID（条件付き=E14 のみ・corrected calorie は別フィールド・表示 grams 不変）。
