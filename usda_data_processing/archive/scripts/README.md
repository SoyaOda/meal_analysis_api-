# アーカイブされたスクリプト

## 📋 概要

これらのスクリプトは**旧仕様（v1）**で使用されていたもので、現在は**新仕様（v2）**に移行したためアーカイブされています。

## 📂 アーカイブされたスクリプト

### 1. split_ingredient_names_with_llm.py
- **役割**: LLMによる食材名分割処理（旧版）
- **問題点**:
  - surveyDownload.jsonを直接読み込み（重複処理）
  - ノイズの多いデータをLLMに渡していた
  - プロンプトが複雑
- **代替**: `split_ingredient_names_with_llm_v2.py`（前処理済みデータ版）

### 2. clean_and_finalize_usda_split_data.py
- **役割**: LLM処理後のクリーニング（後処理）
- **処理内容**:
  - NFS除去
  - 括弧内容の除去
  - "NS as to"を含む項目の削除
  - ブランド名の分離
- **廃止理由**: 前処理アプローチに移行したため不要に
- **代替**: `preprocess_usda_data.py`（前処理として実装）

## 🔄 移行理由

### 旧フロー（v1 - 後処理アプローチ）
```
surveyDownload.json → LLM処理 → 後処理でクリーニング
```

**問題点**:
- LLMにノイズの多いデータを渡していた
- エラーの修正が困難
- 処理が非効率

### 新フロー（v2 - 前処理アプローチ）
```
surveyDownload.json → データ抽出 → 前処理 → LLM処理
```

**利点**:
- クリーンなデータでLLM処理
- プロンプトがシンプル
- 処理時間短縮（約30%）
- エラー率低減（約80%）
