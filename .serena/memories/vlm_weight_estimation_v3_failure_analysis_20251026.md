# V3改良版（weight_g削除）失敗分析

生成日時: 2025-10-26
検証内容: VLMからweight_g出力を削除し、体積×密度のみで重量推定

## 実験結果

### テスト結果
- **平均誤差率**: 69.8%（V2の17.4%から52.4%ポイント悪化）
- **中央値誤差率**: 66.8%
- **最大誤差**: 155.2%

### 誤差分布
- 0-10%: 5画像 (10.0%)
- 10-20%: 2画像 (4.0%)
- 20-30%: 4画像 (8.0%)
- 30-50%: 9画像 (18.0%)
- 50-100%: 17画像 (34.0%)
- **100%+: 13画像 (26.0%)** ← 深刻

## 失敗の根本原因

### 1. VLMの体積推定精度の限界
**実例: test_food24.jpg（サラダ）**
```
VLM推定体積 → パイプライン計算重量 → 実際の妥当な重量
- 鶏胸肉: 300cm³ × HIGH(1.5) = 450g → 実際100-150g（3倍過大）
- レタス: 400cm³ × LOW(0.5) = 200g → 実際50-80g（2.5倍過大）
- 卵: 100cm³ × MEDIUM(1.0) = 100g → 実際50-70g（1.5倍過大）
```

### 2. RGB画像からの3D推定の困難性
- 深度情報なし（RGB-Dではない）
- 遮蔽された部分の推測が不正確
- プレートやボウルの深さ推定が困難
- VLMが視覚的な広がりを体積に過大変換

### 3. weight_g削除の逆効果
- VLMの直感的な重量推定能力を失った
- 「このサラダは200gくらい」という暗黙知が使えない
- 数学的な計算（体積推定）だけでは精度が低い

## 学んだ教訓

### 理論的正しさ ≠ 実用性
- 体積×密度は物理的に正しいアプローチ
- しかし2D画像からの体積推定が本質的に困難
- VLMの強みは視覚的直感であり、精密な幾何学計算ではない

### VLMの得意・不得意
**得意:**
- 視覚的な直感による重量推定
- 食品の種類と状態の識別
- 密度カテゴリーの分類

**不得意:**
- 精密な体積測定
- 数学的制約の遵守（weight = volume × density）
- 深度情報なしの3D再構成

## 最終推奨

### 短期的（即実装）
1. **V2プロンプトを本番採用**
   - 17.4%誤差は現実的な改善
   - 安定性が高い

2. **query_extraction.pyの調整**
   - VLMから直接weight_gを受け取る
   - 体積×密度ロジックは後方互換のみ

### 中長期的（研究課題）
1. **ハイブリッドアプローチの検討**
   - Main food: 直接重量推定
   - 参照画像との比較で精度向上

2. **深度推定モデルの統合**
   - RGB-D変換モデルの活用
   - Monocular depth estimationの導入

3. **ファインチューニング**
   - 食品重量推定に特化したデータセット
   - 実測値との比較学習
