## 🎯 根本原因分析

### 1. VLM（画像認識）レベルの問題

#### A. v5_qwen3の密度値エラー
```json
{
  "weight_derivation": {
    "density_g_cm3": 0.3,  // 異常に低い
    "estimated_volume_cm3": 400,
    "weight_g": 120  // 実際の半分以下
  }
}
```
**原因**: 調理済み食品の密度を0.3-0.5 g/cm³と設定（正常値: 0.8-1.2）

#### B. アイテム見落とし（全プロンプト共通）
- 野菜類: 60件（lettuce, tomato, cucumber等）
- ソース類: 32件（dressing, sour cream等）
- **原因**: 小物や混在物の検出閾値が高すぎる

#### C. 食品誤認識
- chicken → pork: 3件
- pasta → rice: 2件
- **原因**: 視覚的類似性への依存、コンテキスト不足

### 2. USDA検索レベルの問題

#### A. 低rerankerスコア
- 27.3%のケースで最適マッチ選択失敗
- prosciutto → "ham, sliced" (誤: 栄養価が大幅に異なる)

#### B. 検索クエリの不適切さ
- "mixed greens" → マッチせず（正: "lettuce, mixed"）
- "fajita tacos" → 分解失敗

### 3. 栄養計算レベルの問題

#### A. カロリー密度の誤算
- 揚げ物: 実際の40%で計算
- チーズ料理: 実際の60%で計算
