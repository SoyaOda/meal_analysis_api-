## 1. パイプライン概要

### 1.1 全体アーキテクチャ

```
[食事画像] → [VLM] → [JSON出力] → [USDA検索] → [栄養計算]
                ↑
          プロンプト最適化対象
```

### 1.2 USDA検索パイプライン（5段階）

`apps/freeform_usda_meal_analysis_api/services/hybrid_search.py`

| 段階 | コンポーネント | 説明 |
|------|---------------|------|
| 1 | BM25 Searcher | キーワードベース検索 |
| 2 | FAISS Vector Search | Qwen3-Embedding-8Bによるセマンティック検索 |
| 3 | RRF Fusion | BM25とVectorの結果をRRFで融合 |
| 4 | Weighted Fusion | 重み付き融合 |
| 5 | DeepInfra Reranker | 最終リランキング |

### 1.3 データベース情報

- **エントリ数**: 13,564件
- **データソース**: USDA FoodData Central
- **メタデータ**: `apps/freeform_usda_meal_analysis_api/data/faiss/usda_metadata.json`

## 3. 最終テスト結果（5回実行平均）

### 3.1 バッチ評価結果サマリー

**テスト日時**: 2025-12-21
**テスト条件**: 50画像 × 5回実行 = 250サンプル/プロンプト×モデル

| プロンプト | モデル | MAE | 30%+誤差率 | CV | 一貫性率 |
|-----------|--------|-----|-----------|-----|----------|
| **Original** | GPT-5.1 | 14.8% | **8.0%** | 5.1% | 30.0% |
| **Original** | **Gemini** | **14.5%** | **8.0%** | **1.9%** | 80.0% |
| D (Improved) | GPT-5.1 | 14.6% | 8.8% | 6.0% | 30.0% |
| D (Improved) | Gemini | 15.3% | 9.6% | 7.6% | 84.0% |
| E (Refined) | GPT-5.1 | 15.3% | 10.1% | 3.4% | 34.0% |
| E (Refined) | Gemini | 14.5% | 12.8% | 5.4% | 72.0% |
| F (Hybrid) | GPT-5.1 | 15.0% | 10.8% | 12.6% | 34.0% |
| F (Hybrid) | Gemini | 15.1% | 13.6% | 4.7% | 86.0% |
| G (Weight Cal) | GPT-5.1 | 15.4% | 10.0% | 7.0% | - |
| G (Weight Cal) | Gemini | 14.4% | 13.2% | 4.2% | - |

### 3.2 最終結論

```
┌─────────────────────────────────────────────────────────────┐
│  最適構成: Original プロンプト + Gemini-3-Flash            │
│  MAE: 14.5% | 30%+誤差率: 8.0% | CV: 1.9%                  │
└─────────────────────────────────────────────────────────────┘
```

**重要な発見**:
1. **Originalプロンプトが最良** - 追加ルールは改善せず悪化
2. **プロンプト複雑化は逆効果** - D, E, F, G すべてOriginalより劣る
3. **Geminiの一貫性が最高** - CV 1.9%（同じ画像に同じ結果）
4. **30%+誤差率は8.0%が限界** - プロンプト改善では突破困難

## 4. プロンプト別詳細分析

### 4.1 なぜOriginalが最良か

| 仮説 | Originalの対応 | 追加プロンプトの問題 |
|-----|---------------|-------------------|
| シンプルさ | 必要十分なルール | ルール過多で混乱 |
| 汎用性 | 食品カテゴリに偏りなし | 特定パターンに過適合 |
| VLMの自由度 | 判断の余地あり | 過度な制約で判断阻害 |

### 4.2 追加ルールが失敗した理由

| プロンプト | 追加ルール | 失敗理由 |
|-----------|-----------|---------|
| D | 詳細な分解ルール | VLMの自然な判断を阻害 |
| E | Composite優先 | 分解すべき料理も複合化 |
| F | D+Eの混合 | 矛盾するルールで混乱 |
| G | 重量補正指示 | 過度な補正で精度低下 |

### 4.3 Prompt Gの具体的失敗

**追加した内容**:
```
WEIGHT ESTIMATION BIAS CORRECTION
1. LIQUID-HEAVY DISHES - 固形成分のみで重量推定
2. FLAT/SPREAD DISHES - 厚さ×面積で現実的な推定
3. DENSITY AWARENESS - 高/低/中密度の区別
4. OIL/FAT DETECTION - 光沢・揚げ・クリーミー表面の検出
```

**結果**: Gemini 30%+誤差率 8.0% → 13.2%（悪化）

**分析**: 一般化したつもりでも、VLMに追加の判断基準を与えることで、元々正しかった判断が歪められた
